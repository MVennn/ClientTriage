## 本版内容

**工具**

- 修复 `verify-gemini.sh` —— 失败退出时清理已启动的临时 Chrome，并在启动前检查 CDP 端口是否被别的实例占用；避免下一次复测连到旧实例、抓到过期状态。超时提示改为实际的约 100 秒。
- 修复 `cdp.js` —— 每条 CDP 请求加 20 秒超时，调试口断开时立即失败而不是永久挂起；启动时检测 Node 22+。
- 修复 `clear-chrome-region.js` —— 非 Windows 环境给出明确提示；写入前再确认一次 Chrome 没有启动。
- 修复 `check-secrets.py` —— git 异常时报错退出，不再「扫描 0 个文件通过」。

**文档**

- README 的运行时要求改为 Node.js 22+（与工具实际依赖的全局 `WebSocket` 一致）。

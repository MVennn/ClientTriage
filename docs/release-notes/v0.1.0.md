## 本版内容

**工具**

- 新增 清地区种子 —— 工具 → `tools/clear-chrome-region.js`；完全退出 Chrome 后清掉 `Local State` 与 `Preferences` 里 5 个 `variations_*_country` 键，写前留 `.bak-region-<时间戳>` 备份，可重复执行。
- 新增 Gemini 复测 —— 工具 → `tools/verify-gemini.sh`；切 WiFi → SSH 跑路由器侧检查 → 起带 9223 调试端口的临时 Chrome → 抓控制台 → 截图 → 清理并切回热点，你日常那个 Chrome 全程不动。
- 新增 抓控制台 —— 工具 → `tools/cdp.js`；把「页面只剩输入框」变成一条明确的控制台错误（渲染状态 / console / 异常 / 网络失败 / 非 2xx 响应）。

**文档**

- 新增 LNA 与 fake-IP 机制 —— 文档 → `docs/LNA-FAKE-IP.md`；Chrome 155 的 Local Network Access 与 mihomo fake-IP 冲突的机制、原始证据与解法。
- 新增 排错手册 —— 文档 → `docs/TROUBLESHOOTING.md`；按现象检索：Gemini 页面只剩输入框 / 扩展装不上 / Play 更新转圈 / 账号被判不支持的国家 / 流媒体打不开 / 社媒加载不全，每节给可执行命令与「客户端问题还是路由器问题」的判据。
- 新增 踩坑总汇 —— 文档 → `docs/PITFALLS.md`；改种子被覆盖、CDP 端口占用、headless 截图与真实浏览器的差异、判 302 要用 GET、API 必须走路由器代理、出口 IP 地理标签不可信、节点健康探测要用大页面等 13 条。
- 新增 维护流程 —— 文档 → `docs/MAINTENANCE.md`；地区种子要能重复执行、证据文件命名与保留期限、工具脚本副作用的登记位置。
- 新增 文档规则 —— 文档 → `docs/DOC-RULES.md`；分类定位、单一正本映射表、链接纪律、变更触发矩阵、孤儿文档零容忍。

**结论**

- 修复 Gemini 只剩输入框的判据 —— 以前拿「网页外壳能打开」当修好的依据，误判过一次；现在判据是「UI 完整加载」：控制台无 LNA / CORS 拦截、非 2xx 里没有 gstatic / googleapis 的 bundle 请求、DOM 里有输入框以外的内容。
- 修复 阶段诊断的过期结论 —— 2026-10-19 那份「已修复」结论不完整：同一 LNA 机制仍导致 Gemini 只剩输入框，最终修法是 `fake_ip_filter` 补 `+.gstatic.com` / `+.googleapis.com`；该文降级为历史证据原文，结论以 LNA 篇为准。
- 修复 出口判定的口径 —— 第三方 GeoIP 与服务方判定在 28 个出口上全部分歧（27 个被判 `cc=CN`，只有 1 个判 `IN`）；现在只用服务方自己的国家标记判定。

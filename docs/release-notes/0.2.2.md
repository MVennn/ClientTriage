**两个维护守卫的一轮边界兜底：漏报堵上、误报修掉，扫描口径与文档正本对齐。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/ClientTriage/issues/new/choose) 反馈 —— 请附上 Chrome / Windows 版本、执行的命令与输出原文。

## 本版内容

**守卫**

- 修复 `check-secrets.py` 漏报 —— 「本机用户目录」的豁免从**整行放行**改为逐命中段判断：同一行里「已脱敏引用 + 完整真实路径」混写时，真实路径不再跟着漏掉；同一行的第二个命中现在也查（旧实现只看每行首个）。
- 修复 豁免口径 —— 截断 / 占位用户名的写法按正本只对文档类文件生效（旧代码从未实现这条限定），并补上反斜杠形式的占位（`C:\Users\You\...` 不再误报）。
- 修复 `check-secrets.py --all` 名不符实 —— 旧实现全树遍历、只排除固定目录，并不遵循 `.gitignore`；现在走 `git ls-files`，`vault/` 等本地私有目录不再进扫描。
- 修复 `check-docs.py` 三处边界 —— 文件带 BOM 时首标题锚点不再丢、指向冻结目录（`docs/archive/` 等）文档的锚点不再必然误报、被检目录与仓库不同盘符时不再整个崩掉。
